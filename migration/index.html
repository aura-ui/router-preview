Minimal migration

Three changes, not a rewrite.

Keep your pages and links. Identify the content region, declare the routes, and install the custom elements.

Step 1

Keep ordinary links

Add one opt-in attribute. The original href remains the no-JS fallback and the canonical destination.

navigation.html
<nav>
  <a href="/" aura-router-link>Home</a>
  <a href="/about/" aura-router-link>About</a>
</nav>

Step 2

Declare the HTML views

extract selects the same content region from full HTML responses and adopts it on first paint.

routes.html
<main id="content">
  <h1>The server rendered this</h1>
</main>

<aura-outlet></aura-outlet>
<aura-router extract="#content">
  <aura-route path="/" view="/"></aura-route>
  <aura-route path="/about/" view="/about/"></aura-route>
</aura-router>

Step 3

Install once

The router runs only in the browser. Static hosting, PHP, Rails, Django, Express and other backends can keep serving HTML as before.

main.js
import { AuraRouter } from '@auraui/router';

AuraRouter.install();
