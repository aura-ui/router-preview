The upgrade path

Progressive by default

The browser and server remain in charge of the first visit. Aura starts after that, adopts the existing page, and intercepts only eligible same-origin links.

01 / HTML

Real pages

Each URL returns meaningful HTML for users, crawlers and no-JS browsing.

02 / ADOPT

No duplicate first fetch

The live #content is adopted instead of immediately re-rendered.

03 / NAVIGATE

SPA after boot

Later links fetch HTML, extract the next view and update browser history.

The entire starting point

Routes stay in markup

No framework adapter is required. Use plain HTML, vanilla Custom Elements or Lit.

index.html 
<aura-router extract="#content">
  <aura-route path="/" view="/"></aura-route>
  <aura-route path="/about/" view="/about/"></aura-route>
</aura-router>

<a href="/about/" aura-router-link>About</a>

<script type="module">
  import { AuraRouter } from '@auraui/router';
  AuraRouter.install();
</script>
