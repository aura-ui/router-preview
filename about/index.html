How it works

The server keeps its job.

Aura Router does not invent server rendering. Your host returns ready HTML; the browser paints it; Aura progressively adds navigation after boot.

01 / REQUEST

The browser requests a normal URL.

02 / PAINT

The returned HTML is immediately useful.

03 / ADOPT

Aura adopts the existing content root.

04 / UPGRADE

Eligible links now navigate on the client.

One URL, two modes

Failure is graceful

Progressive enhancement means the baseline stays useful. JavaScript improves navigation; it does not own access to content.

JavaScript unavailable

  • Links trigger document navigation
  • Every URL returns complete content
  • Browser history works natively
  • Search engines receive real HTML

Aura Router installed

  • Same-origin links are intercepted
  • Only #content is replaced
  • Shared chrome remains mounted
  • Prefetch, lifecycle and cache are available

Verify it yourself

No hidden app shell

Open DevTools, disable JavaScript, and use the navigation. Then enable it and watch the boot token remain unchanged across transitions.
